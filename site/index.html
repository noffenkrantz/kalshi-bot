One-time setup on this device. To start runs from this page, paste a GitHub token that can only run this bot. It's saved in this browser and nowhere else.

  1. On GitHub: profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → kalshi-bot.
  3. Permissions → Repository permissions → Actions: Read and write. Generate it and copy it.

Or run it on GitHub instead: tap Run workflow, then Run workflow again.
